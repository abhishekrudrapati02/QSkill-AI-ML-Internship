## Projects Completed

### 1. Iris Flower Classification

The Iris dataset is used to classify flowers into three species:

- Setosa
- Versicolor
- Virginica

#### Algorithm Used
Logistic Regression

#### Steps Performed
- Loaded the Iris dataset
- Explored the dataset
- Visualized the flower measurements
- Split the data into training and testing sets
- Trained a Logistic Regression model
- Generated predictions
- Evaluated the model using accuracy and confusion matrix

#### Result

The model achieved an accuracy of **96.67%** on the test data.

### 2. House Price Prediction

The California Housing dataset is used to predict house prices using numerical features.

#### Algorithm Used
Linear Regression

#### Steps Performed
- Loaded the California Housing dataset
- Explored the dataset
- Checked for missing values
- Analyzed basic statistics
- Split the data into training and testing sets
- Trained a Linear Regression model
- Generated house price predictions
- Evaluated the model using Mean Squared Error and R² Score

#### Result

- Mean Squared Error: **0.5559**
- R² Score: **0.5758**
